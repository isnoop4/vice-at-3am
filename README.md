VICE AT 3 AM is a static, offline cover studio that turns your photos into GTA 6-style multi-panel poster art: a cast of five characters with role labels, a giant chrome title overlapping the panels, a press-quote strip, tagline ribbon, gold seal and barcode — in a cold-blue neon night world with warm ember accents. Pick a panel, pick a photo from the library (or upload your own), drag to position it, edit the captions, switch the grade and layout, and export a real PNG in 1080×1080, 1080×1350 or 1920×1080.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests: every script, image and font is a file under app/.
