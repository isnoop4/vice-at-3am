VICE AT 3 AM — a GTA 6-style cover art maker for the cold side of Vice City. Turn a photo and a caption into a multi-panel night poster: a hero panel plus three captioned scenes, a chrome title with cyan glow, a magenta neon-script subtitle, police-radio caption chips, a Leonida licence plate and the tagline strip — then export it as a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080.

The field is orange sunsets; this one is 3 AM: deep navy streets, cyan and magenta neon, wet asphalt, rain. One-click grades (Night / Sunset / Ink / Duotone), two layouts (Night Grid / Full Bleed), drag-to-position and zoom per panel, several panels from one photo or several, editable captions, and a Surprise me button that rolls a whole new cover. Everything runs offline in a desktop browser from its own static files — photos never leave the machine.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080. Load a photo (or use the four image-model-made night samples), pick a panel, drag the photo into place, write a caption, and Export PNG.
